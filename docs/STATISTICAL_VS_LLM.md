# Statistical vs LLM

Le LLM ne modifie jamais les probabilites, les cotes, l'EV, la CLV, Kelly ou le settlement.

Mesures prevues:

- couverture;
- Brier et log loss des sous-ensembles retenus;
- CLV moyenne et mediane;
- ROI fictif;
- cout API;
- cache hit rate;
- faux vetoes et vetoes utiles;
- biais de selection.

La Phase 5 ajoute `backtest compare` avec baseline marche no-vig sur la meme cohorte 1X2 quand les cotes sont disponibles.
